## Overview

My finished QR Code project for Frontend Mentor. The project was built using HTML and styled using an external CSS stylesheet. It showcases a QR code that links directly to the Frontend Mentor website, with a light-blue background and a centered card layout. The card contains the QR code along with a call to action that is emphasized through font weight, spacing, and layout design. This project helped me practice Flexbox, responsive design, spacing, alignment, and overall frontend styling fundamentals.

## My process

I began by constructing the centered card layout using a div element wrapped around the image and text sections. Once the card structure was complete, I styled it by adding a background color, border radius, padding, and spacing to better match the design preview. After finishing the card itself, I styled the rest of the page by centering the layout with Flexbox and adjusting the text colors, font styles, and spacing. Finally, I completed the project by fixing smaller spacing inconsistencies, improving the responsive design for different screen sizes, and cleaning up the footer section.
